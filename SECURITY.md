# Security

Do not post credentials, reconnect tokens, private media links, or exploit details in a public issue.

Report vulnerabilities privately using the repository owner's contact details on their [GitHub profile](https://github.com/krishnaagarwal2025-a11y), or GitHub's private vulnerability reporting option if it is enabled. No response-time or support guarantee is currently published.

Keep environment files and runtime databases out of Git. Rotate exposed credentials. Room codes are invitations, not host authentication; the server validates membership, roles, and reconnect identities.
