Foyer help

Shared rooms for video, music and conversation. Everyone gets their own synchronized player.

Watch & Listen

Choose a room type before creating a room. The host can switch modes; that loads the matching local demo and clears bookmarks for the previous media. Listen rooms accept audio sources. Add YouTube, Vimeo, SoundCloud, or direct audio/video/on-demand HLS by expanding Add a link below the player. Discover contains catalog and song search; People contains preferences, settings and host transfer. Room opens chat, queue, polls and moments.

YouTube uses its official visible player, with its own controls and advertising. Foyer does not extract audio, hide ads, or grant access to private videos. Actual source availability depends on the provider. Live HLS is not synchronized.

In Listen → Discover, search a song or artist, then choose Search music. The host can Play a result directly inside Foyer; everyone can queue it. No YouTube Music tab or copied link is required. If search is unavailable, choose another provider or expand Add a song link.

Audius offers artist-published music, not every commercial recording. Navidrome is open-source personal-library software: the operator supplies the music collection; Navidrome does not include a commercial song catalog. Foyer keeps Navidrome credentials on the server and protects shared searches with a separate library code.

Synchronize the room

Only the host can use Sync room or S. Everyone pauses at one timestamp while the devices exchange timing packets and confirm readiness/alignment, then resumes automatically at a shared start time. An unavailable or autoplay-blocked device keeps the whole room paused; the host can cancel or retry after fixing it. Reported alignment is an estimate, not a guarantee of zero frame or speaker error. Refresh all participants' tabs when updating Foyer. Subscription-service titles use the experimental companion on their service pages.

Foyer Companion · experimental

  1. Download the companion ZIP and extract it to a folder.
  2. In Chrome or Edge open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, and select the extracted folder.
  3. On an authorized Netflix watch page, Prime Video title page or Hotstar/JioHotstar title, open the extension popup, enter the Foyer server origin, then select Allow server + this site. The extension uses the named provider sites and requests access only to your chosen Foyer server. Use HTTPS for a public deployment.
  4. Reload the title page and open the Foyer panel. Enter your name and create a room or join by its six-character code.
  5. The host can bind the current title, copy an invite, transfer host, chat, react and control playback. Each viewer opens the same title in their own signed-in tab and joins with the extension.
  6. If automatic title recognition fails, use Use this title. Ads are not skipped or modified. The host can mark an ad as playing; playback pauses and may resume after the ad.

Page changes, closed players, regional editions, ads and service restrictions can prevent control. Signed-in Netflix/Prime/Hotstar playback has not been verified by the fixture suite. The extension reads the title page URL, document title and accessible video state. It never reads login forms, cookies, passwords, protected media URLs or DRM keys. It does not send a stream through Foyer. The included ZIP is for developer installation and has not been published in the Chrome Web Store.

Playback & connection help

  • If autoplay is blocked, select Enable playback on this device. This is a local permission action, not a guest room-sync control.
  • Offline commands pause until reconnect. Return within the 15-second grace period to keep your identity; otherwise rejoin as a new participant. An absent host is replaced deterministically.
  • Host controls are the default. Guests can chat, react, queue, vote and bookmark. Host transfer or collaborative controls grant room control.
  • External services need internet and may restrict playback. The local video and music demo work offline.
  • Room codes are invitations. Chat is bounded; spoilers are hidden until revealed, not encrypted.

Privacy & project support

Foyer has no registration, analytics or ad trackers of its own. Anonymous room identities and bounded room activity are held by the server. Embedded providers receive their normal playback requests and apply their own policies. Empty rooms are removed after reconnect grace expires.
